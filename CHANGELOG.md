## [0.1.0] - 2026-10-09

### Added

- Interactive terminal chat (`agys`) with `/help`, `/clear`, and `/exit`.
- One-shot prompts: `agys "your question"`.
- Pluggable providers: OpenAI, Anthropic, and local Ollama.
- Config resolution from CLI flags, `agysyy.toml`/`agysyy.json`, and environment variables.
- Distribution pipeline: npm (`agyssyy.exe` + README), static website, and full
  GitHub Releases.
